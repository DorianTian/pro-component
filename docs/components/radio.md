# Radio 单选框

基于 Element Plus `ElRadio` / `ElRadioGroup` / `ElRadioButton` 的统一封装。统一 shadcn-vue 视觉风格，API 同 Element Plus。

## 导出组件

- `Radio` -- 单个单选框
- `RadioGroup` -- 单选框组
- `RadioButton` -- 按钮式单选框

## API

完整 Props/Events/Slots 同 [Element Plus Radio](https://element-plus.org/zh-CN/component/radio.html)，所有原生属性均可透传。
