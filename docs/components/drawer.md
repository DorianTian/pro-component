# Drawer 抽屉

基于 Element Plus `ElDrawer` 的统一封装，默认挂载到 body。

## 默认配置

| 属性           | 默认值 | 说明                          |
| -------------- | ------ | ----------------------------- |
| `appendToBody` | `true` | 默认挂载到 body，避免层级问题 |

## API

完整 Props/Events/Slots 同 [Element Plus Drawer](https://element-plus.org/zh-CN/component/drawer.html)，所有原生属性均可透传。
