# Select 选择器

基于 Element Plus `ElSelect` 的统一封装，默认启用 `clearable` 和 `filterable`。

## 默认配置

| 属性         | 默认值 | 说明           |
| ------------ | ------ | -------------- |
| `clearable`  | `true` | 默认可清除     |
| `filterable` | `true` | 默认可搜索过滤 |
