# DatePicker 日期选择器

基于 Element Plus `ElDatePicker` 的统一封装，默认启用 `clearable` 并统一日期格式。

## 默认配置

| 属性          | 默认值         | 说明               |
| ------------- | -------------- | ------------------ |
| `clearable`   | `true`         | 默认可清除         |
| `valueFormat` | `'YYYY-MM-DD'` | 统一日期字符串格式 |
