# Checkbox 多选框

基于 Element Plus `ElCheckbox` / `ElCheckboxGroup` / `ElCheckboxButton` 的统一封装。统一 shadcn-vue 视觉风格，API 同 Element Plus。

## 导出组件

- `Checkbox` -- 单个多选框
- `CheckboxGroup` -- 多选框组
- `CheckboxButton` -- 按钮式多选框

## API

完整 Props/Events/Slots 同 [Element Plus Checkbox](https://element-plus.org/zh-CN/component/checkbox.html)，所有原生属性均可透传。
